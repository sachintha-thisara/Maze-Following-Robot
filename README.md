# Autonomous Maze-Solving Robot

An autonomous maze-solving robot developed as a project at the University of Moratuwa.

**Key Features**
* Sensors: Distance mapping and wall detection using HC-SR04 ultrasonic sensors.
* Algorithms: Left/Right Hand rule logic for maze navigation and wall recovery.
* Signal Processing: Float Median Filter for accurate sensor data.
* Control System: Wall-follow PD controller for precision tracking.

**Hardware Components**
* Arduino Microcontroller
* HC-SR04 Ultrasonic Sensors
* Motor Driver
* Custom-built chassis

**Repository Structure**
* /Code - Contains the Arduino control code.
* /Mechanical-Design - Contains the mechanical design files (DXF, SLDPRT).
